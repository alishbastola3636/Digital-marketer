# Alish Portfolio Project

## Overview
This project is a personal portfolio website for Alish, a digital marketing agent and content writer. It is designed with a premium, minimal aesthetic and includes multiple pages for marketing-focused storytelling, case insights, testimonials, analytics, and blog content.

## Pages included
- Home: landing page with hero section, services, work, and CTA
- About: personal story and working process
- Analytics: marketing performance metrics and visual charts
- Blog: article cards with strategy and growth content
- Testimonials: client feedback and social proof
- Contact: inquiry form and contact details

## Tech stack
- HTML5
- CSS3
- JavaScript

## Run locally
Open the project folder in a browser, or serve it locally with a simple web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Design direction
- Minimal, luxury-inspired look
- Warm neutral palette with dark premium background
- Elegant serif headings with modern sans-serif body text
- Smooth motion and reveal animations
- Clean marketing-brand presentation

## Notes
The site is intentionally built as a lightweight static portfolio so it is easy to customize, extend, and deploy on GitHub Pages, Netlify, or any static host.
